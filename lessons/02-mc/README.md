# 第 02 课：MC、增量平均与固定学习率

本课接着[第 01 课 TD](../01-td/README.md)，围绕一个问题展开：同样在估计状态价值，实际回报、更新目标和汇总样本的方式有什么区别？计划约 120 分钟，包含 10 分钟休息；按理解程度调整。

## 1. MC 使用本回合实际完整回报

继续固定路径：

```text
A --奖励 0--> B --奖励 0--> C --奖励 1--> 终点 T
```

每个非终止状态只有一个动作，因此策略固定；本课仍在做价值预测，没有学习选择更好的动作。设折扣因子 γ=0.9，从各个状态出发，本次完整回报分别为：

$$
G_A=0+0.9\times0+0.9^2\times1=0.81,
\quad G_B=0+0.9\times1=0.9,
\quad G_C=1.
$$

MC（Monte Carlo，蒙特卡洛）等待回合结束，再用这些实际完整回报作为目标。A 的目标 0.81 来自本回合实际收到的奖励，不读取 B 的价值估计。

如果初始估计全为 0，学习率 α=0.2，首次 MC 更新后，A、B、C 的估计分别为 0.162、0.18、0.2。

## 2. 与一步 TD 的区别

| 方法 | 更新时机（本课实现） | 更新目标 |
|---|---|---|
| MC | 等回合结束，取得完整回报后 | 本次实际完整折扣回报 |
| TD(0) | 每次观察到一步转移后 | 当步奖励 + 折扣后的下一状态估计；终止时只有当步奖励 |

两者都可以通过“旧估计 + 学习率 ×（目标 − 旧估计）”更新。相同的更新外形不表示目标来源相同。

在同样的轨迹、初始化、α=0.2、γ=0.9 下，TD 按 A、B、C 的前向顺序逐步在线更新；MC 在回合结束后累计实际回报：

| 回合 | TD 的 A、B、C 估计 | MC 的 A、B、C 估计 |
|---|---|---|
| 1 | [0, 0, 0.2] | [0.162, 0.18, 0.2] |
| 2 | [0, 0.036, 0.36] | [0.2916, 0.324, 0.36] |
| 3 | [0.00648, 0.0936, 0.488] | [0.39528, 0.4392, 0.488] |

TD 同样能够利用终点奖励。上述设置下，奖励先影响 C 的估计，再经由下一状态估计影响 B、A；不能说“MC 能使用最终奖励，TD 不能”。这个传播顺序与零初始化、前向在线 TD(0) 实现有关，不是所有 TD 实现的固定回合规律。

运行：[mc_td_comparison.py](experiments/mc_td_comparison.py)。这个确定性短路径用于理解更新机制，不能据此认定 MC 普遍更好。

## 3. 一次实际回报不等于期望价值

将终止奖励改成 0 或 2，各以 1/2 的概率出现；不同回合独立，其他条件保持不变。A 的实际回报便可能是 0 或 1.62。

$$
v_\pi(A)=\mathbb{E}[G_A]=\frac12\times0+\frac12\times1.62=0.81.
$$

某一回合的 MC 目标为 1.62，与真实期望价值 0.81 不同，是随机采样的正常结果。需要区分：

- **实际回报**：这一次经历得到的样本。
- **真实价值**：给定任务和策略下，回报的期望。
- **价值估计**：用有限样本计算的数。

## 4. 普通平均也能写成一次更新

设第 n 个实际回报为 G_n，前 n 个回报的普通平均为 m_n。过去 n−1 个回报的总和为 (n−1)m_(n−1)，因此：

$$
m_n=\frac{(n-1)m_{n-1}+G_n}{n}
=m_{n-1}+\frac1n(G_n-m_{n-1}).
$$

这就是增量样本平均（incremental sample mean）。它不需要保存所有过去的回报，只需保存旧平均和样本数。

加入第 n 个样本时，更新系数为 1/n。第一次为 1，第二次为 1/2，之后依次减小。实现时要先增加样本数，再用新的样本数作分母。

这里的 n 是对应状态的回报样本数。本例每回合恰好访问 A 一次，所以 A 的样本数与回合数相同；一般不能直接使用全局环境步数。

### 手算

前三个回报为 1.62、0、1.62，平均为 1.08。第四个回报为 0：

$$
m_4=1.08+\frac14(0-1.08)=0.81.
$$

第五个回报为 1.62：

$$
m_5=0.81+\frac15(1.62-0.81)=0.972.
$$

注意新样本仍是实际回报。不能先算出新的普通平均，再把这个新平均当作固定 α 更新的目标。

## 5. 固定学习率是另一种汇总方式

同样使用实际完整回报作目标，也可以固定学习率：

$$
u_n=u_{n-1}+\alpha(G_n-u_{n-1}).
$$

例如旧估计同样为 1.08，固定 α=0.2，收到回报 0 后，新估计为 0.864，与普通平均的 0.81 不同。

| 汇总方式 | 当前新样本的系数 | 历史样本的作用 |
|---|---|---|
| 普通样本平均 | 1/n | 前 n 个样本最终各占 1/n |
| 固定 α | 始终为 α | 较早样本的权重随更新次数衰减 |

在第 5 个样本时，1/n 恰好等于 0.2，不意味着两种方式始终相同。到第 6 个样本时，普通平均使用 1/6，固定学习率仍为 0.2。

两种方式都可以用来汇总 MC 回报。MC 的关键是目标来自实际完整回报；普通平均或固定 α 决定如何汇总这些样本。

## 6. 随机回报为什么引起波动

在本例的固定策略、独立同分布且有界回报条件下，普通样本平均依据大数定律收敛到期望值 0.81。这不要求有限样本恰好等于真值，也不表示每一步都更接近。

固定 α 持续给新回报相同的调整系数。在回报随机为 0 或 1.62 的任务里，即使始终从同一个 A 出发，也会保持随机波动。这不需要存在不同动作可选；不要把随机回报混淆成策略在多种动作间切换。

普通平均的 1/n 随样本数减小，因此后期单个新样本的影响较小；固定 α 的影响不会这样缩小。单次实际调整还取决于目标与旧估计的差。

## 7. 休息与对照实验

完成前面的概念和手算后，休息约 10 分钟，再运行：[incremental_mean.py](experiments/incremental_mean.py)。全部脚本只用 Python 标准库，无需 GPU 或安装第三方包。

在仓库根目录运行：

```bash
python lessons/02-mc/experiments/mc_td_comparison.py
python lessons/02-mc/experiments/incremental_mean.py
```

也可完整复制任意一个脚本到 [Programiz 在线 Python](https://www.programiz.com/python-programming/online-compiler/) 运行。

运行前预测：

1. 同一串回报下，只改变另一种估计的固定 α，普通平均会改变吗？
2. α=0.05、0.2、0.8 哪个对单个新回报反应更强？这是否保证它更准确？
3. 第 1000 回合的普通平均必须恰好等于 0.81 吗？

脚本先为每个 seed 生成一份回报序列，再让各种 α 读取相同序列，保持比较条件一致。随机种子由脚本开头的 `SEEDS = (7, 19, 42)` 控制；只运行一个种子时可改为 `SEEDS = (7,)`，保留单元素元组的逗号。

输出前五列依次为 seed、固定 α、回合数、普通平均、固定 α 估计。先检查 seed=7 的第 10、100、1000 回合和最后五个值，再查看其他种子。

`matches_full_average` 比较增量均值与直接求和平均，允许浮点舍入误差。这项检查验证的是算术实现，不证明策略表现好坏。真值 0.81 只用于检查，不进入更新函数。

## 8. 迁移到机器人成功率

固定执行同一个抓取策略，前 10 次成功 8 次，普通成功率为 0.8。新增第 11 次失败，样本记为 0：

$$
m_{11}=0.8+\frac1{11}(0-0.8)=\frac8{11}\approx0.7273.
$$

成功次数仍为 8，总次数变成 11；这和直接统计相同。这里估计的是固定策略的成功率，没有训练出新策略。
