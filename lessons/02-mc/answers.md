# 第 02 课参考解答

对应[习题](exercises.md)。计算题应同时检查目标来源、样本数和数值。

## 1. 各状态的 MC 目标

A、B、C 的完整折扣回报分别为 0.81、0.9、1。初始估计均为 0，α=0.2 后分别为 0.162、0.18、0.2。

这些目标来自整段实际奖励，不是下一状态的价值估计。

## 2. 单次样本与期望

观察到终止奖励 2 时，A 的本次目标为 `0.9**2 * 2 = 1.62`。因为终止奖励 0、2 各占一半，真实期望价值为 0.81。样本与期望不同不说明算法出错。

## 3. 两种汇总方式

1. 第四个样本为 0，普通平均：`1.08 + (0-1.08)/4 = 0.81`。
2. 固定 α=0.2 的另一份估计：`1.08 + 0.2*(0-1.08) = 0.864`。新目标是回报 0，不是第一问的新平均 0.81。
3. 第五个样本的系数为 1/5：`0.81 + (1.62-0.81)/5 = 0.972`。此时系数恰好等于 0.2，不表示以后也相同。

## 4. 第十个样本

普通平均：`0.8 + (1.6-0.8)/10 = 0.88`。

固定 α=0.2：`0.8 + 0.2*(1.6-0.8) = 0.96`。

## 5. 成功率

`0.8 + (0-0.8)/11 = 8/11 ≈ 0.7273`。分母 11 是当前已观察的抓取次数；新增失败未增加成功数，所以成功数仍为 8。

## 6. 概念解释

1. 不会。普通平均的增量系数始终为 1/n；改变的是另一种估计中的固定 α 参数。
2. 不能。固定 α 的 MC 更新与普通样本平均不是同一种汇总方式。固定 α 会持续给新回报相同的调整系数；不能直接套用普通平均的收敛结论。
3. 会。即使只有一个非终止状态、只有一个动作，只要终止奖励随机，新目标就可能变化。波动不要求策略切换动作。
4. 能。之前零初始化、按 A、B、C 顺序在线更新的 TD(0) 实验里，终点奖励先影响 C，再经由后续状态的估计影响 B、A。TD 的自举也能学习延迟奖励。

## 7. 实验核对

MC/TD 前三回合与[讲义表格](README.md#2-与一步-td-的区别)一致。

增量均值实验 seed=7、1000 回合时：

| 固定 α | 普通平均 | 固定 α 估计 |
|---|---:|---:|
| 0.05 | 0.792180 | 0.775560 |
| 0.2 | 0.792180 | 0.918555 |
| 0.8 | 0.792180 | 1.358295 |

最后五个回报与 α=0.2 的估计：

```text
last_5_returns: [0.0, 1.62, 1.62, 0.0, 1.62]
last_5_means: [0.790482, 0.791314, 0.792144, 0.791351, 0.79218]
last_5_fixed: [0.540301, 0.75624, 0.928992, 0.743194, 0.918555]
```

同一输入下，改变固定 α 不改变普通平均；固定 α 对新样本的响应保持较大。第 1000 回合普通平均不必等于真值 0.81。不同 seed 会生成不同样本，不应要求各 seed 的末值一致，也不能凭一次运行的末值给出普遍算法排名。
