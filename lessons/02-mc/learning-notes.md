## 已提交的手算与解释

1. 三个回报为 1.62、0、1.62，平均为 1.08；第四个回报为 0。用户正确计算普通平均为 `(3*1.08+0)/4=0.81`。
2. 另一份估计更新前同为 1.08，固定 α=0.2。用户起初误把新普通平均 0.81 作为更新目标；提示本次实际回报为 0 后，正确重算为 `1.08+0.2*(0-1.08)=0.864`。
3. 前四个回报的平均为 0.81，第五个回报为 1.62。用户独立正确选择步长 1/5，并计算新平均为 0.972。
4. 用户正确预测：同一串回报下，只改变另一种估计的固定 α，不改变普通样本平均。已补充精确表述：普通平均的增量实现本身使用 1/n；改变它自己的系数，一般就不再是普通平均。
5. 用户正确解释：普通平均随着 n 增大，步长趋近 0；固定学习率保持不变，因此对新回报的反应更明显。单次实际更新幅度还取决于回报与旧估计的差。
6. 机器人前十次抓取成功八次，第十一次失败。用户正确给出步长 1/11，以及更新式 `0.8+(1/11)*(0-0.8)`。该式等于 8/11，约为 0.7273；此前只要求写算式，提交已满足要求。

普通样本平均的增量形式：

$$
m_n=m_{n-1}+\frac{1}{n}(G_n-m_{n-1}).
$$

这里 n 是对应状态或所评估事件的样本数，不能一概替换成全局环境步数。当前固定路径每回合访问 A 一次，所以 A 的样本数与回合数相同。

## 最后两道概念检查

**固定 α 的 MC 估计持续波动，能否据此断言算法出错？**

用户判断“不能”正确，但解释中使用了“多种状态”“多种选择中跳动”。需要把波动来源说清楚：本例每回合都从同一个 A 出发，执行固定策略，但实际回报可能为 0 或 1.62。固定 α 持续给新回报相同的更新系数，因此估计会继续受随机回报拉动。无需发生策略选择或状态种类变化，也能出现这种波动。

在固定分布、独立且有界的回报样本条件下，普通样本平均服从大数定律；固定 α 的加权更新不等同于普通样本平均，不能直接套用相同的收敛结论。已给出这处修正，尚未在全新题目上单独复测。

**TD 能不能利用最终奖励，学到较早状态 A 的价值？**

用户正确解释：“会先传给近处状态，再逐渐传递到较早状态。”这符合之前零初始化、按 A、B、C 前向顺序逐步更新的 TD(0) 实验。TD 使用下一状态估计进行自举，能够学习延迟奖励；不能把两种方法的差异概括成“MC 能利用终点奖励，TD 不能”。
