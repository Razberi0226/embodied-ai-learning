## 模块A：从一个目标到整段trajectory

### 固定过程与编号

```text
位置：0          1          2          3          4
状态：A --0-->   B --0-->   C --0-->   D --R-->   T
```

T是真正终点。每episode只有四次转移；确定实验R=1，扩展实验R在0和2中各以一半概率取值。策略固定，没有学习选择动作，也没有policy improvement。

gamma=0.9。两种奖励设置中E[R]=1，因此true state values都为：

```text
[v(A), v(B), v(C), v(D)] = [0.9**3, 0.9**2, 0.9, 1]
                         = [0.729, 0.81, 0.9, 1.0]
```

这里v是true state values，程序中的values是估计。某次R=0不表示true state values突然变为0。

### 选取前缀，而不是把整episode奖励都塞给n步函数

奖励数组为rewards，长度T=4。从位置t开始：

1. n步方法的末端位置k=min(t+n,T)；MC的k=T。
2. 传入的observed rewards片段是rewards[t:k]。Python切片包含t，不包含k。
3. 若k=T，已到终点，不读取终点估计。
4. 若k<T，后续value estimate是old_values[k]，其折扣指数是实际片段长度k-t。

例如从B（t=1）看两步：使用B→C、C→D的两笔奖励，末端是D（位置3）；目标为0+gamma*0+gamma**2*V(D)。从C（t=2）计划看三步，实际只有C→D、D→T两笔奖励：目标为0+gamma*R。

适用条件：完整episodetrajectory已经收集好，末端T为真正终止。此函数不负责在线等待数据，也不处理时间上限截断。

### 今天统一frozen estimates，明确更新规则

本实验episode结束后保存old=values[:]，所有状态都用同一份old构造目标，再一起得到新values。

如果R=1、初始全0、alpha=0.2、n=2，首episode更新C时，片段是[0,1]，目标为0.9，新C估计为0.18。计算同episodeA的目标时，使用的是old中的C=0，不能直接使用刚得到的0.18。

这样可以清楚比较信息经过多少episode传到A。今天报告的是这种episode末冻结更新的n步预测实验；它的episode数结果不能直接代表在线机器人上的更新等待时间或实际运行耗时。后续再学习在线缓冲和更新时机。

## 模块B：速度、波动与公平比较

### 用什么衡量结果

统计维度补充（2026-10-27）：每次evaluation在4个states上计算一个RMSE；每个episode结束都做一次evaluation，再对最后50个RMSE做mean。较低mean error不等于更小fluctuation。详细例子见同目录“04-what-rmse-averages-over.md”。

本玩具过程能解析算出真值，所以每episode直接计算四个状态的均方根误差：

$$RMSE=\sqrt{\frac{1}{4}\sum_{s\in\{A,B,C,D\}}(\hat V(s)-v(s))^2}.$$

例如真值[1,1]、估计[0,2]时，两项误差为-1、1，平方平均为1，RMSE=1。正负误差不能相互抵消。

确定实验记录A首次为正的episode、RMSE首次低于0.02的episode、最终RMSE。首次达标只描述第一次越过阈值，不保证后续一直达标，随机情况下尤其要谨慎。

随机实验的主要分数是最后50episode各次RMSE的平均；再把5个种子的分数汇总为平均与种子间标准差。它不是“先平均50次估计，再计算一次RMSE”。标准差在此只是5次运行的描述，不能当作显著性检验。

### 公平比较与适用范围

- 共同保持：同一路径、gamma、alpha、初始化、episode预算、冻结更新方式、误差定义。
- 每个种子先生成一份终止奖励列表，四种方法读取同一份列表；只改变n。
- 分开报告：确定奖励的学习速度和随机奖励下的误差。单次最后估计更高不等于更准确。
- 固定alpha在随机样本下可能持续波动。n增大减少中间估计参与的位置，但不能据此断言n越大在所有条件下都更好。
- 这里是真值已知的policy evaluation；没有学到新动作。未来机器人任务真值通常未知，需要另设计独立评估。

具身联系：把四步看作接近物体、对准、闭合夹爪、抬起，只有最后成功才给奖励。这里观察的是成功信息怎样影响更早状态的value estimate，距离“学会抓取动作策略”还需要控制算法和任务建模。
