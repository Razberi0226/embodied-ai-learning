## 公式与参考实现

二步经历已收集齐时，先使用两笔实际奖励：r1 + gamma*r2；仅在第二步到达的状态未终止时，再添加gamma**2*next_value。

旧估计value只用于更新：new_value = value + alpha*(target-value)。

```python
def two_step_update(value, r1, r2, next_value, terminal,
                    gamma=0.9, alpha=0.2):
    target = r1 + gamma * r2
    if not terminal:
        target += gamma ** 2 * next_value
    new_value = value + alpha * (target - value)
    return target, new_value
```

以上为导师整理的参考实现，已在本地执行原三组输入并核对结果。本函数仅处理已经观察到两次实际转移的情况，terminal指第二步到达的状态真正终止；第一步提前终止和时间上限截断尚未实现。

## 需要间隔复习的点

1. 目标中三个量的对应关系：第一步奖励、第二步奖励、两步后状态的价值估计。折扣依次为1、gamma、gamma平方，不能把当前状态旧估计加进目标。
2. terminal=True表示已经真正终止，应取消自举项；not terminal表示未终止。本次在明确提示后改正，后续用新场景复查。
3. 更新量是alpha*(target-value)，更新后估计还要加回旧估计value。
