## 从摸底到理解

| 最初的理解或疑问 | 修正后的认识 |
|---|---|
| 奖励与回报不确定如何区分 | 奖励是一步反馈；回报是从一个起点出发的后续折扣累积 |
| TD 目标可能是“最优状态”或最终正确答案 | 目标是一个数，可能含有估计误差，会随下一状态估计变化 |
| 正奖励超过当前估计才上调 | 比较的是整个 TD 目标与当前估计 |
| 第一回合 A 会变化，因为 delta 存在 | delta 可以等于 0；第一次更新 A 时，B 的估计尚未更新 |
| 大学习率可能一定更慢 | 当前确定性任务中 0.8 最快；随机样本下还需观察估计波动 |
| 训练改变了状态的价值 | 训练改变的是价值估计；固定任务和策略的真实价值没有因此改变 |

## 两状态实验的实际结果

配置：A → B → T，奖励 0、1，gamma=0.9，alpha=0.2，初始估计全 0。

```text
1 0.0 0.2
2 0.036 0.36
50 0.899827 0.999986
```

解释：A 的即时奖励虽为 0，但后续 B 有价值，因此 A 能逐步学到正价值。

## 学习率实验：一次被实验修正的预测

原预测：0.2 最快，其次 0.05，最后 0.8，担心 0.8 步幅太大。

保持相同任务、初始化、200 回合预算与误差标准后，得到：

```text
alpha=0.05，首次达标回合=128
alpha=0.2，首次达标回合=30
alpha=0.8，首次达标回合=5
```

修正：在这个确定性任务中，大步幅更快接近目标。这个证据不支持“大步幅在所有任务中都更好”。

随机奖励手算也已完成：当前估计为 1、真实价值为 1，却采样到终止奖励 0 时，alpha=0.8 得到 0.2，alpha=0.05 得到 0.95。较大学习率对单次样本反应更强。

## 折扣因子检查

正确预测：两状态任务改为 gamma=0.5 时，真实价值为 A=0.5、B=1。

解释：更远的奖励被赋予更小的权重，不表示同一条路线实际走得更差。

## 独立三状态扩展

配置：A → B → C → T，奖励 0、0、1，gamma=0.9，alpha=0.2，初始估计全 0。

课堂运行结果：

```text
1 0.0 0.0 0.2
2 0.0 0.036 0.36
50 0.808959 0.899827 0.999986
```

已正确实现 A、B、C 的前向在线更新、终止状态处理，以及跨回合保留价值估计。

对 A 首次为正的解释正确：第 1 回合 C 先变正，第 2 回合 B 也变正，第 3 回合 A 才变正。

仓库中的整理版增加了第 3 回合输出，便于核对这一预测。
