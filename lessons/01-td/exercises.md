# 第 01 课练习

先写预测和理由，再运行代码。参考解答见 [answers.md](answers.md)。

## 一、概念检查

1. 奖励 reward 与回报 return 有什么区别？
2. 状态价值为什么依赖策略？
3. TD 目标是否一定是真实价值或最优价值？为什么？
4. 收到正奖励，是否一定上调价值估计？
5. 某次 TD 误差为 0，能否证明当前估计正确？举出本课中的反例。
6. 固定路径实验有没有学到更好的走法？训练改变的是什么？
7. 训练回报提高，是否足以证明算法更好？还需要哪些证据？

## 二、单次更新

统一使用学习率 alpha=0.1、折扣 gamma=0.9，当前估计 V(s)=3。

分别计算 target、delta 和更新后的估计：

| 情况 | 本次奖励 | 下一状态 | 下一状态估计 |
|---|---:|---|---:|
| A | 1 | 未终止 | 2 |
| B | 1 | 未终止 | 5 |
| C | 1 | 已终止 | 不使用 |

为什么相同的奖励可能导致不同的更新方向？

## 三、更新顺序

路径 A → B → T，奖励依次 0、1，gamma=0.9、alpha=0.2，初始估计全为 0。

1. 手算前两个回合结束后的 A、B 估计。
2. 解释第一回合走到终点拿到奖励后，A 为什么仍然为 0。
3. 运行 [two_state_td.py](experiments/two_state_td.py) 核对。

## 四、参数实验

1. 先预测 alpha=0.05、0.2、0.8 在本例中谁更快达到相同精度，再运行 [learning_rate_comparison.py](experiments/learning_rate_comparison.py)。
2. 每个状态下一步就终止，奖励为 0 或 2、各半概率。真实价值与当前估计均为 1；本次实际奖励为 0。分别算 alpha=0.8 和 0.05 的新估计。哪个更易受单次样本影响？
3. 两状态路径保持不变，gamma 改为 0.5。预测真实价值，再运行 [discount_factor_comparison.py](experiments/discount_factor_comparison.py)。A 的价值变小，是否表示原路线表现变差？

## 五、代码扩展

把路径改为 A → B → C → T，奖励依次 0、0、1，gamma=0.9、alpha=0.2，初始估计全为 0。

1. 先算 A、B、C 的真实价值。
2. 按实际转移顺序在线更新，跨回合保留价值估计。
3. 打印第 1、2、3、50 回合结束后的三个估计。
4. 解释 A 首次变成正数的回合数。

完成后对照 [three_state_td.py](experiments/three_state_td.py)。
