# 第 01 课参考解答

建议先完成 [练习](exercises.md)，再对照本文件。

## 概念题

1. 奖励是一步转移的反馈；回报是从指定起点开始，将后续奖励按折扣累积起来。
2. 策略决定之后如何行动，从而影响未来回报的分布与期望。
3. TD 目标一般含有下一状态的当前估计，不一定等于真实价值，也不一定是最优价值；固定策略评估并不直接求最优策略。
4. 不一定。学习率为正时，上调条件是 target 高于当前估计，而非奖励高于当前估计。
5. 不能。两状态路径全零初始化时，第一次 A → B 的奖励和下一状态估计都为 0，因此 delta=0，但 A 的真实价值是 0.9。
6. 没有学习新走法，因为每个状态只有一个动作。训练改变的是对既定策略的价值估计。策略改进还需要比较动作并改变选法。
7. 不充分。还需明确比较基线、训练与评估条件，在适当的多次运行和其他初始状态或场景中检查结果；不能只看某次训练曲线。

## 单次更新

| 情况 | target | delta | 新估计 |
|---|---:|---:|---:|
| A：下一状态估计 2 | 2.8 | -0.2 | 2.98 |
| B：下一状态估计 5 | 5.5 | 2.5 | 3.25 |
| C：下一状态终止 | 1 | -2 | 2.8 |

相同奖励下，后续价值估计和是否终止不同，目标可能位于当前估计的不同方向。

## 两状态更新顺序

- 第 1 回合结束：A=0，B=0.2。
- 第 2 回合 A → B：target=0.18，delta=0.18，A 更新为 0.036。
- 第 2 回合结束：A=0.036，B=0.36。

第一次更新 A 时还没有更新 B。之后 B 学到奖励不会自动触发 A 再更新一次。

## 参数实验

确定性两状态实验达到最大绝对误差小于 0.01 的回合数：

- alpha=0.05：128。
- alpha=0.2：30。
- alpha=0.8：5。

只支持本任务和本比较设置中的速度排序，不能推断所有任务都应使用更大的 alpha。

终止奖励随机为 0 或 2、当前估计 1、本次观察到 0 时：

- alpha=0.8：新估计 0.2。
- alpha=0.05：新估计 0.95。

较大学习率在这次观察中受到更大影响。单次更新可能偏离真实期望价值。

gamma=0.5 的两状态路径真实价值为 A=0.5、B=1。变化来自对远期奖励权重的调整，不表示原路线的实际奖励变少。

## 三状态扩展

真实价值为 A=0.81、B=0.9、C=1。

| 回合 | A 估计 | B 估计 | C 估计 |
|---|---:|---:|---:|
| 1 | 0 | 0 | 0.2 |
| 2 | 0 | 0.036 | 0.36 |
| 3 | 0.00648 | 0.0936 | 0.488 |
| 50 | 0.808959 | 0.899827 | 0.999986 |

本例中 A 第 3 回合首次为正：第 1 回合 C 更新，第 2 回合 B 能使用 C 的新估计，第 3 回合 A 能使用 B 的新估计。这依赖全零初始化和按 A、B、C 的前向在线更新顺序。
